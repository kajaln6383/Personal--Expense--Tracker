# Personal Expense Tracker

## About the Project
A command-line application developed using Python to manage personal expenses.

##Features
- Add new expenses
- Validate expense amount and date
- View all recorded expenses
- Calculate total spending
- Menu-driven interface
- Exit option

## Technologies Used
- Python
- Lists and Dictionaries
- Functions
- Exception Handling
- Date Validation

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

```bash
python main.py
```
